Endpoints

GET /search

Search CineSubz by movie or series title. Returns title, page URL, IMDb score and quality badge.

full request url
https://days-charger-editor-stayed.trycloudflare.com/search?q=deadpool
example response
{ "results": [ { "title": "Deadpool", "url": "https://cinesubz.co/movies/deadpool/", "imdb": "8.0", "quality": "HD" } ], "count": 1 }
GET /movie

Scrape a CineSubz movie page. Returns every download button with quality label and a pre-resolved direct .mp4 URL when possible.

full request url
https://days-charger-editor-stayed.trycloudflare.com/movie?url=https://cinesubz.co/movies/deadpool/

Only cinesubz.co / cinesubz.lk page URLs are accepted.

POST /start-resolve

Decrypt a protected player link and return final .mp4 URLs. Runs in background — you get a jobId immediately.

full request url
https://days-charger-editor-stayed.trycloudflare.com/start-resolve
request body
{ "directUrl": "https://drive.csplayer2.space/server1/abc123/file.mp4" } // or use a page URL instead: // { "pageUrl": "https://cinesubz.co/..." }
example response
{ "success": true, "jobId": "a1b2c3d4e5f6", "poll": "/check-status/a1b2c3d4e5f6" }
GET /check-status/:jobId

Poll a resolve job. status is pending, done, or failed. Jobs expire after 10 minutes.

full request url
https://days-charger-editor-stayed.trycloudflare.com/check-status/a1b2c3d4e5f6
example response
{ "status": "done", "links": ["https://.../file.mp4"] }
GET /rate-status

Check remaining quota for your IP. Does not consume your daily limit.

full request url
https://days-charger-editor-stayed.trycloudflare.com/rate-status

Rate Limit Rules

50 requests per IP per day. Counter resets at 00:00 UTC every day. When your quota is exhausted, every endpoint returns HTTP 429 with a JSON body describing the reset time.

Every response includes X-RateLimit-Limit, X-RateLimit-Remaining and X-RateLimit-Reset headers (CORS-exposed). Resolve jobs run through a small concurrency pool, so sending a few requests back-to-back is safe — they settle in order.

How to Use · In Order

Step 1. GET /search — find your movie (get its CineSubz page URL).
Step 2. GET /movie — get download buttons for that page.
Step 3. POST /start-resolve — decrypt a protected player link → get jobId.
Step 4. GET /check-status/:jobId — poll until done, read final .mp4 links.
Tip. GET /rate-status at any time to check your remaining quota (free).
javascript · full flow
const API = "https://days-charger-editor-stayed.trycloudflare.com/"; // Step 1 · Search const search = await fetch(`${API}/search?q=deadpool`).then(r => r.json()); const movieUrl = search.results[0].url; // Step 2 · Get download buttons const movie = await fetch(`${API}/movie?url=${encodeURIComponent(movieUrl)}`).then(r => r.json()); const first = movie.details.downloadLinks[0]; // Step 3 · Start resolve job const job = await fetch(`${API}/start-resolve`, { method: "POST", headers: { "Content-Type": "application/json" }, body: JSON.stringify({ directUrl: first.directUrl }) }).then(r => r.json()); // Step 4 · Poll const result = await fetch(`${API}/check-status/${job.jobId}`).then(r => r.json()); console.log(result.links);
